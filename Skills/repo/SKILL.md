# Skill de Repositorio - Vision Code

Este archivo define el entorno de repositorio para el proyecto.

**Regla principal:**
Cada vez que se trabaje en esta carpeta (`d:\VISION CODE`), el repositorio de destino y origen de referencia será siempre:
`https://github.com/MGDIGUITAL/Vison-Code.git`

**Directrices para Antigraviti:**
- Todo el código escrito en este workspace debe estar orientado a ser versionado en el repositorio `MGDIGUITAL/Vison-Code.git`.
- Al realizar commits o revisar el control de versiones, se asume que este es el repositorio remoto (`origin`).
- Este proyecto corresponde a la empresa del usuario y el flujo de trabajo debe estar alineado con los estándares del repositorio.
